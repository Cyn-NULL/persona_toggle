페르소나 토글 모듈
🙋 RisuAI 모듈

유저 페르소나,
토글 하나로 바꿔쓰기

커스텀 토글과 로어북 조건문을 조합해서, 대화 중 유저 페르소나의 성격·나이·특이사항 같은 속성을 드롭다운이나 직접입력으로 바꿔 쓸 수 있는 모듈입니다.

기본 개념
🎚️

커스텀 토글

select 형태로 선택지를 만들어두는 스위치. 고른 값은 전역 변수로 저장됩니다.

📖

로어북 조건문

토글 값을 읽어서, 값에 맞는 성격 지침만 골라 프롬프트에 삽입합니다.

토글에서 고른 값이 getglobalvar로 저장되고, 로어북의 {{#when}} 블록이 그 값을 읽어 분기하는 구조입니다.

토글 만들기

커스텀 토글에 아래 형식으로 등록합니다.

UserP=🙋페르소나 성격=select=🔸비활성,💞귀여움,🐇소심함,🌑무뚝뚝,🛏️귀차니즘,🍸어른여유,🔫위트·염세

순서대로 변수명 / 표시 이름 / 타입 / 선택지 목록입니다. 선택지는 왼쪽부터 0, 1, 2... 순으로 인덱스가 매겨지며, 0번은 항상 비활성 취급이라 첫 항목을 "비활성"으로 두는 게 편합니다.

로어북에 지침 넣기

각 선택지에 대응하는 지침을 로어북 항목으로 등록합니다.

{{#when::{{getglobalvar::toggle_UserP}}::is::1}}
## {{user}} 성격
### 사랑스럽고 귀여움 (햇살 애교형)
- 성격 키워드: 애교 많음, 해맑음, 솔직한 감정 표현
- 말투 가이드: 말끝이 부드럽고 말랑함
{{/when}}

is::1이 토글에서 선택한 두 번째 항목(💞귀여움)에 대응합니다. 선택지 개수만큼 {{#when}} 블록을 만들어두면 됩니다.

예시로 넣어둔 6가지 성격
💞

1귀여움

애교 많고 해맑은 햇살형

🐇

2소심함

눈치 보고 위축 잘하는 유리멘탈형

🌑

3무뚝뚝

겉으론 덤덤, 속으론 부끄럼 많은 샤이형

🛏️

4귀차니즘

만사 귀찮은 나른 무기력형

🍸

5어른여유

능글맞고 여유로운 성숙형

🔫

6위트·염세

시니컬한 블랙코미디 지능캐형

확장하기: 성격 외 다른 항목도 같은 방식으로

이 구조는 성격에만 한정되지 않습니다. 나이, 외형, 가족관계, 직업처럼 유저 캐릭터를 구성하는 다른 요소도 똑같은 패턴으로 세분화해서 추가할 수 있습니다.

1

새 토글 등록

UserA=🙋페르소나 나이=select=🔸비활성,10대,20대
2

전담 로어북 새로 생성

이 나이 항목을 담당할 로어북 항목을 하나 추가합니다.

3

값별 분기 작성

{{#when::{{getglobalvar::toggle_UserA}}::is::1}}
{{user}}는 10대이다.
{{/when}}

같은 방식으로 UserF(가족), UserJ(직업), UserL(외형) 등 원하는 만큼 계속 늘려갈 수 있습니다. 변수명만 겹치지 않게 관리하면 됩니다.

응용: select 대신 text로 직접 입력받기

정해진 선택지 중 고르는 대신, 타입을 text로 바꾸면 사용자가 직접 글자를 입력해서 그 내용을 그대로 지침에 반영할 수 있습니다.

UserW=📝페르소나 메모=text

로어북에서는 인덱스 비교 대신, 값이 비어있는지(null)만 확인해서 입력이 있을 때만 지침을 삽입합니다.

{{#when::{{getglobalvar::toggle_UserW}}::isnot::null}}
## {{user}}의 특이사항 혹은 숨겨진 비밀
{{getglobalvar::toggle_UserW}}
{{/when}}

select형은 정해진 성격·나이 같은 카테고리를 고르는 데 적합하고, text형은 "이번 캐릭터만의 특이사항", "숨겨진 비밀"처럼 매번 달라지는 자유 서술을 넣고 싶을 때 적합합니다.

⚠️ 토글 변수명(UserW)과 로어북에서 참조하는 변수명(toggle_UserW)이 반드시 같은 이름을 가리켜야 합니다. 둘이 어긋나면 값이 항상 비어있는 것으로 처리돼 지침이 삽입되지 않습니다.
정리 팁
GROUP

토글이 다른 모듈들과 섞여서 목록이 지저분해 보일 때, 그룹으로 묶어서 정리할 수 있습니다.

=페르소나 커스터마이징=group
UserP=🙋페르소나 성격=select=🔸비활성,💞귀여움,🐇소심함
UserA=🙋페르소나 나이=select=🔸비활성,10대,20대
==groupEnd
CAPTION

토글이 많아져서 헷갈릴 때, 토글 아래에 짧은 설명을 붙일 수 있습니다.

=페르소나의 성격을 바꿔보자=caption
UserP=🙋페르소나 성격=select=🔸비활성,💞귀여움,🐇소심함
요약
커스텀 토글(select) + 로어북 {{#when}} 조건문으로 페르소나 속성을 전환
선택지 인덱스는 0부터 시작, 0번은 보통 "비활성"으로 고정
성격뿐 아니라 나이·외형·가족·직업 등 원하는 속성으로 확장 가능
자유 서술이 필요하면 text 타입 + isnot::null 조건으로 직접입력형 구성
group / groupEnd로 묶고, caption으로 설명 추가 가능
